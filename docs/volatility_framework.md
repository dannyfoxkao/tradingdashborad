## 1. 核心概念

**波動率只量「動多大」，不管「往哪動」。** 一根 +9.5% 和一根 -9.5% 對標準差、ATR 的貢獻完全相同。因此「高波動」有兩種本質不同的型態：

- **單邊**：能量大、方向一致（mean 大、std 大）。順勢策略的燃料。
- **雙向**：能量大、方向每天翻（mean≈0、std 更大）。順勢策略的絞肉機。

**性質切換**（單邊→雙向）是最重要的出場訊號：波動總量不變甚至放大，但方向消失。實例：國巨 2026/6/18 前 20 日（單邊：19 天中 16 天收紅、日均 +4.68%、累積 +89%）→ 6/18 後（雙向：13 天僅 5 天收紅、日均 -0.64%、std 反而從 4.28 升到 6.71、隔日翻轉率 33%→50%）。

### ATR 的價格水準陷阱

ATR 是絕對金額。股價從 100 漲到 200，同樣 3% 的日震幅會讓 ATR 從 3 元變 6 元，看似波動放大實為價格墊高。**一律使用標準化版本 ATR% = ATR / 收盤價 × 100**，才能跨時間、跨股票比較。

## 2. 指標定義

| 指標 | 公式 | 量什麼 | 備註 |
|---|---|---|---|
| ATR14% / ATR5% | rolling(TR,N).mean() / close × 100 | 能量（含跳空） | 5 日版為快線，領先 14 日版反映 regime 變化 |
| HV20 | std(log_ret, 20) × √252 × 100 | 能量（收對收） | SNR 的分母 |
| Parkinson20 | √( mean(ln(H/L)², 20) / (4ln2) ) × √252 × 100 | 能量（盤中形式） | 只用高低價，抓甩轎 |
| SNR（訊噪比） | mean(ret,20) / std(ret,20) | 方向純度 | 日頻 Sharpe；×√20 ≈ 趨勢 t 值 |
| 隔日翻轉率 | rolling10 內 sign(ret) 變號比例 | 方向穩定度 | SNR 的快版前哨 |

### 指標間的關係

- **HV 是 SNR 的分母**：SNR = 趨勢漂移 ÷ HV。HV 單獨看永遠分不出單邊/雙向。
- **Parkinson ÷ HV 比值**診斷能量的釋放形式：
  - 比值 << 1：能量以跳空、漲跌停鎖死釋放（隔日跳世界，留倉風險高）。國巨 5 月漲停潮：HV 82 vs Park 69。
  - 比值走高至 ≈1 以上：盤中對殺主導（當沖絞肉，停損易被插針掃）。國巨 6/18 後 Park 升幅 > HV 升幅。
- **快慢搭配**：ATR5% 對 ATR14%、10 日 SNR（或翻轉率）對 20 日 SNR。快線報警、慢線確認。20 日 SNR 分子是均值，天生遲鈍，一根 -10% 要數日才拉動。

### 象限框架（每日狀態判讀）

```
                SNR 高（方向純）
   ┌──────────────┬──────────────┐
   │  緩漲趨勢     │  單邊行情     │
   │  沿5日線爬    │  抱緊+雷達開機 │
低 ├──────────────┼──────────────┤ 高
能 │  休眠盤整     │  雙向絞殺     │ 能
量 │  觀察名單     │  縮部位/離場  │ 量
   └──────────────┴──────────────┘
                SNR ≈ 0（只剩噪音）
```

性質切換 = 從右上掉到右下。監控目標就是抓這個移動。

## 3. 進場規則（第一根紅 K）

**本質：這是賭賠率結構，不是預測。** 進場當下無法區分「單邊行情第一天」和「只有這一天」。勝率通常 < 50%，期望值來自不對稱：錯了照紀律賠 5~8%，對了抱 50~90%。一次弘塑 2~4 月可以付十次停損的學費。

**訊號定義**：日漲幅 ≥ 5~6.5% 且 成交量 ≥ 1.5×20 日均量。

**濾網（改善基本率，非預測）**：
- 族群同步：多檔同族群同日亮燈 > 單檔孤軍。
- 基本面催化：有漲價/訂單/題材的第一根比純籌碼發動耐久。
- 位階：底部突破 > 漲三倍後的「又一根」（後者已靠近雙向絞殺區）。

**已知缺陷與補丁（3711 教訓）**：
- **量能濾網自我鈍化**：持續一年的長趨勢裡 20 日均量被永久墊高，「爆量」不再出現。3711 於 2026/5 之後 8 根 ≥5% 大紅 K 量比全部僅 0.7~1.4×，導致零再進場、錯過 472→727。
- **補丁**：再進場必須有一條不依賴量能的路徑——出場後「收盤重新創 20 日新高」即可回補。
- 「20 日新高」濾網會殺死盤整區內的點火（弘塑 2/26 案例），嚴格版全年 -22.1%、寬鬆版 +23.7%。預設用寬鬆版。

**執行細節**：連續大漲後的隔日開盤常有獲利了結，讓開盤先表態 30~60 分鐘再執行；Parkinson 主導期避免開盤市價單。

## 4. 出場架構（分批，核心設計）

事前無法知道手上是「弘塑型」（脈衝+絞殺）還是「3711 型」（長趨勢爬坡），因此**不調參數、改分批**：

### 交易倉：2×ATR14 移動停利
- trail = 進場後最高收盤價 − 2×ATR14（元）
- 防弘塑型絞殺。弘塑回測 +23.7%（5 筆、勝率 2/5、最大單筆 +61.5% 支付全部虧損）。
- 缺點：對爬坡型趨勢太緊，3711 僅 +29.4%（4 筆全獲利但都是小段）vs 買抱 +351%。

### 核心倉：性質切換出場
- 條件：20 日 SNR 跌破 0 且 結構破壞（跌破突破平台/趨勢線）。
- 容忍深回檔以換取抱住 3711 型行情：3711 同進場、SNR<0 出場版 +73.0%。
- 已知假警報：3711 的 3/9、5/19 警示與三次 SNR 出場事後皆為洗盤點——指標對型態、不對個股，這是分批存在的理由。

### 輔助出場訊號（警示層，非直接觸發）
- 性質切換警示：SNR 由 5 日均 >0.15 掉到 <0.05，且 ATR14% ≥ 滾動 120 日第 80 百分位。
- 隔日翻轉率跳升至 ≥50%、Parkinson/HV 比值走高。
- 結構出場常優於 ATR 出場：弘塑最後一筆，跌破 3565 平台（7/6 @3425）比 ATR 觸發（7/7 @3185）多保住約 7%。

### 部位管理
- **ATR 定倉**：部位股數 = 單筆可承受虧損金額 ÷ (ATR × 停損倍數)。ATR% 倍增 → 部位自動減半。停損放寬與部位縮減必須同時發生。
- 雙向段的反彈（如國巨 7/9 +6.27%、振幅 9.97%）是減碼點不是加碼點；追砍常砍在短線低點，用「反彈至跌破平台下緣不過即出」處理殘餘部位。

## 5. 處置股資料處理（國巨案例）

處置期間分盤撮合（5~20 分鐘一盤）會人為壓低波動讀數，污染前後對照。**剔除法**：
1. 整段移除處置交易日，時間軸直接縫合。
2. 接縫日 TR 只用當日高低價（不用前收，避免假跳空）。
3. 跨縫報酬設 NaN，rolling 用 min_periods 跳過。
4. Parkinson 只用當日高低價，天然不受接縫影響。

效果：國巨 6/18 前後對照從模糊（Levene p=0.48）變清晰（ATR14% 5.94→7.84、HV 71.2→84.3、std 4.28→6.71、p=0.14）。

**操作意義**：處置本身是制度訊號——出處置後波動常報復性放大（國巨 6/9 出關後 ATR 一路墊高至 10.07% 分割後新高）。pipeline 應維護處置日曆，出關日前後升高警戒。

```
狀態機輸出：
  波動加速中: ATR5% > ATR14% 且 ATR14% ≥ 滾動一年 P80
  波動降溫中: ATR5% 跌破 ATR14% 且連續走低
```
